# Zusha plugin

This repository contains the distribution package for Zusha, the conversational
learning companion for [סְבֹרֶא](https://daily.knafaim.app/). The plugin lives in
[`plugins/zusha`](plugins/zusha/README.md) and connects Claude to the hosted
Zusha MCP server. The application and server implementation are maintained
separately.

No credentials are stored in this repository; personal features require each
learner to connect their own account through OAuth. Read the plugin README for
capabilities and access boundaries.
